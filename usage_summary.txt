
## 競馬データ過去戦績追加スクリプト 利用ガイド

このファイルは、競馬のレース結果データに、各出走馬の過去の戦績を特徴量として追加するためのガイドです。

### 1. 関連ファイル

*   **`add_past_performance.py`**:
    *   このスクリプトが、過去戦績を生成する本体です。
    *   指定されたCSVファイルを読み込み、各馬の過去5走分の情報を新しいカラムとして追加し、別のCSVファイルとして保存します。
    *   日付カラム名 (`開催日`) や、馬名カラム名 (`馬名`)、追加したい特徴量 (`features_to_shift`) はスクリプト内で設定されています。

*   **`2023_result.csv`**:
    *   今回、過去戦績を追加する元のデータ（入力ファイル）です。
    *   `database` フォルダ内にあります。

*   **`2023_result_with_past_data.csv`**:
    *   `add_past_performance.py` の実行によって生成された、過去戦績が追加されたデータ（出力ファイル）です。
    *   `database` フォルダ内に保存されます。

*   **`verify_data.py`**:
    *   (参考用) 今回のデータが正しく生成されたかを確認するために使用したスクリプトです。特定の馬のデータを抽出し、元のデータと生成されたデータの比較を行います。

### 2. 使用方法

1.  **スクリプトの実行**:
    *   `add_past_performance.py` はPythonで書かれています。コマンドプロンプト（またはターミナル）を開き、`gemini_sample` ディレクトリに移動してください。
    *   以下のコマンドを実行します。
        ```bash
        python add_past_performance.py
        ```
    *   実行が完了すると、`database` フォルダ内に `2023_result_with_past_data.csv` が生成されます。

2.  **スクリプトのカスタマイズ**:
    *   **入力ファイル/出力ファイルの変更**: スクリプト内の `input_path` および `output_path` 変数を変更することで、処理対象のファイルや出力先を変更できます。
    *   **処理対象の特徴量の変更**: `features_to_shift` リストを変更することで、過去戦績として追加したいカラムを増減できます。
        ```python
        # 例: 着順と斤量のみにしたい場合
        features_to_shift = ['着順', '斤量']
        ```
    *   **過去走数の変更**: `PAST_RACE_COUNT` の値を変更することで、過去何走分のデータを追加するかを調整できます（例: 3走分にするなら `PAST_RACE_COUNT = 3`）。

### 3. 注意事項

*   **カラム名**: スクリプト内の `開催日` (日付カラム) や `馬名` (馬名カラム) は、お手持ちのCSVデータのカラム名と一致している必要があります。異なる場合は、スクリプト内の該当箇所を修正してください。
*   **パフォーマンス**: 大量のデータを処理する場合、`PerformanceWarning` が表示されることがあります。これは処理速度に関する警告で、データは正しく生成されます。もし処理速度が問題になる場合は、より最適化された処理方法を検討することも可能です。

このガイドが、今後のデータ分析にお役立ていただければ幸いです。
